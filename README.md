Purple02 is a visual architecture and page-tree concept for a future P4A web
presence. It translates the Purple Synthesis into a proposed information
hierarchy, design language and staged policy rollout.

## Public page

- [Open the P4A design architecture](https://auraofintelligence.github.io/Purple02/)

## What is here

`index.html` contains the complete interactive presentation, including:

- typography, colour and visual-motif guidance;
- audience framing;
- a three-phase rollout concept;
- a proposed website page tree; and
- sketches for surge, policy and data-dashboard interface modules.

## Open locally

Open `index.html` in a browser. No build step or backend is required.

## Status and boundaries

This is a design-planning prototype. It is not a live party platform, approved
campaign plan, working data dashboard or current policy timetable. Any election
dates, legal assumptions, targets or public claims need fresh verification.
